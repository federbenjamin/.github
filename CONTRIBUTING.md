# Contributing

## Report a bug or ask for a feature

Open an issue in the project's repository. For a bug, say what you did, what you expected, what happened, and which version you ran.

## Send a change

- For anything larger than a small fix, open an issue first so the approach is agreed before you write it.
- One change per pull request, with a title that says what it does.
- Run the project's tests before you push. The commands are in the Contributing section of its README.
- Pull requests are squash-merged.

## Security

Do not report a vulnerability in an issue. Use the [security policy](SECURITY.md).
